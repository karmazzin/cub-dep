# Pets Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add named cat, dog, capybara, and parrot companions with a saved carrier, five active slots, three behavior modes, and one-shot parrot microphone playback.

**Architecture:** Add a focused `Game.pets3d` IIFE for pet state, AI, interactions, microphone capture, and pet DOM UI. Keep pet rendering in the existing Three.js renderer and store serializable pet records in `worldMeta.pets` so existing save paths persist them.

**Tech Stack:** Static HTML/CSS, plain JavaScript IIFEs, Three.js, MediaRecorder, Node smoke tests.

**Spec:** `docs/superpowers/specs/2026-09-18-pets-design.md`

## Global Constraints

- Keep changes small and within the requested pet feature.
- Preserve `window.CubDep` and sequential script loading from `index.html`.
- Add no JavaScript or CSS dependencies.
- Keep `SPEC.md` synchronized with implemented behavior.
- Do not overwrite unrelated uncommitted user changes.
